# 知识依赖图

数据源：`content/knowledge.ts`（知识点）与 `content/course.ts`（课时 prereqs）。网站 `/learn` 页面有可交互的依赖图（按前置深度分列，悬停高亮前置与后续）。

## 重点前置路径（通往同步时序逻辑设计）

```
逻辑运算与逻辑门 → 公式定理与代数化简 → 逻辑函数标准形式 → 卡诺图化简与无关项
        ↓
SR/D 锁存器 → 触发方式（电平/脉冲/边沿） → D、JK、T 触发器与特性方程
        ↓
时序逻辑基础（方程组、Moore/Mealy） → 同步时序电路分析（实验 A）
        ↓
计数器与 74LS161（实验 B） → 同步时序逻辑设计（实验 C） → 序列检测器
```
