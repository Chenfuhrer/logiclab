由独立评审代理只读审查 `lib/` 内核，确认 10 个问题（均附实际运行复现），已全部修复并加入 `tests/unit/review-regressions.test.ts`：

1. 中规模器件 X 精确传播的未知量上限 6 → 12（74LS163 初态 X 时同步清零、74LS194 串行移入初始化原先全为 X）。

3. 异步置位/复位同时有效后同时撤销，状态记为 X。
4. 建立时间只检查本次有效沿真正起作用的数据端（74LS161 仅在置数时检查 D 端；74LS194 按工作方式）。
5. 自由实验台的符号分析按触发器初态参数确定主循环（环形计数器不再被误判）。

7. 相同表达式的多个输出、或直接等于输入的输出各自获得独立网络（经缓冲器）。
8. 最简与或式题中 F=0 答“0”判为最简。
9. 判断与或/或与形式前先拍平嵌套括号。

## 已知问题与限制
- 74HC 电平参数为经验值（⚠️待验证）；74LS00 参数依据 TI 手册但未在本机打开原件核对（⚠️待验证）。

- 开发模式（`next dev`）在快速连续访问大量课时页时曾出现进程崩溃；生产构建与 `next start` 下 36 个路由测试正常。原因未定位。
- 未做性能基准测试，也未在 Firefox/Safari 上测试。
- 解析器文本语法的变量名为“一个字母 + 可选数字”，因此输入 `EN` 会被读作 `E·N`（题目中已规避）；网表提取、综合等内部流程直接使用 AST，不经文本往返。

## 关键技术决策
1. 统一事件驱动引擎同时承担模型 A/B/C：零延迟 = delta 周期，避免两套引擎结论不一致。
2. 触发器两阶段更新由 delta 语义保证，而不是在每个模型中特殊处理。
3. 符号分析只覆盖可严格分析的子集，其余明确拒绝。
4. 卡诺图相邻性按最小项编号判定，循环相邻与 5 变量对称相邻自动正确。
5. 学习模式用 CSS 切换（SSR 包含全部内容），无水合闪烁。
6. 入场动画只用 CSS keyframes + IntersectionObserver（不使用 motion/react）。
