## 学习目标

- 写出 $n$ 位有符号数的**原码、反码、补码**，并说出三者各自的表示范围。
- 理解补码为什么能"把减法变成加法"（模 $2^n$ 运算）。
- 熟练完成补码加减法，并用**符号位法**与 $V = C_n \oplus C_{n-1}$ 两种方法判断溢出。

## 前置知识

- 二进制与十进制互换（"数制与数制转换"）。
- 二进制加法：逐位相加、向高位进位。
- 异或运算 $A \oplus B$：两者不同为 1（在第 2 章系统学习，这里只用到定义）。

## 实际问题

一个 8 位单片机里，变量 `int8_t t = 100;` 再执行 `t = t + 50;`，打印出来却是 $-106$。硬件加法器明明只会做无符号加法，它是怎么处理负数的？又该怎样**用电路**检测到"结果已经错了"？

## 直观解释

<Mode show="basic">

想象一块只有 8 位的里程表，最大显示 255。从 0 往回拨 1 格，它显示 255；往回拨 2 格，显示 254。如果约定"显示 255 就代表 $-1$、254 代表 $-2$"，那么"减 1"就等于"加 255"——因为加 255 后会转满一圈（256）回来。

**补码**就是这个约定：$n$ 位寄存器做的是"模 $2^n$"的加法，把负数 $X$ 存成 $2^n + X$，加法器就能直接做有符号运算。

**溢出**是指真实结果超出了 $n$ 位能表示的范围，好比里程表"转过头"了。两个正数相加得到负数、两个负数相加得到正数，都是溢出的信号。

</Mode>

<Mode show="deep exam">

$n$ 位二进制的加法器天然在 $\mathbb{Z}_{2^n}$（模 $2^n$ 的剩余类）上工作：最高位的进位被丢弃，相当于减去 $2^n$。补码把区间 $[-2^{n-1},\, 2^{n-1}-1]$ 中的每个整数一一映射到 $\{0,\dots,2^n-1\}$ 中与它模 $2^n$ 同余的那个代码，于是加法器的无符号加法自动就是有符号加法——**前提是真实结果仍在这个区间内**。

</Mode>

## 基本原理

设字长为 $n$ 位，最高位为符号位（0 正 1 负），其余 $n-1$ 位为数值位。

| 表示 | 正数 $X \ge 0$ | 负数 $X < 0$ | $n$ 位表示范围 | 0 的表示 |
|---|---|---|---|---|
| 原码 | $0$ + $\lvert X\rvert$ | $1$ + $\lvert X\rvert$ | $-(2^{n-1}-1) \sim 2^{n-1}-1$ | 两种（$+0$、$-0$） |
| 反码 | 同原码 | 原码数值位按位取反 | $-(2^{n-1}-1) \sim 2^{n-1}-1$ | 两种 |
| 补码 | 同原码 | 反码 $+1$，即 $2^n + X$ | $-2^{n-1} \sim 2^{n-1}-1$ | 唯一 |

$$
[X]_{\text{补}} =
\begin{cases}
X, & 0 \le X \le 2^{n-1}-1 \\
2^n + X, & -2^{n-1} \le X < 0
\end{cases}
$$

补码运算规则：

- 加法：$[X]_{\text{补}} + [Y]_{\text{补}} = [X+Y]_{\text{补}} \pmod{2^n}$，符号位与数值位一起参加运算，最高位进位丢弃。
- 减法：$[X-Y]_{\text{补}} = [X]_{\text{补}} + [-Y]_{\text{补}}$；由 $[Y]_{\text{补}}$ 求 $[-Y]_{\text{补}}$：**连同符号位按位取反，再加 1**。

溢出判断（$C_{n-1}$ 为进入符号位的进位，$C_n$ 为符号位产生的进位）：

$$
V = C_n \oplus C_{n-1}
$$

## 电路结构

本课在**逻辑层**讨论数的编码与运算规则。实现补码加减法的电路是"$n$ 位加法器 + 一组异或门"：减法时用异或门把 $B$ 各位取反，并令最低位进位输入 $C_0 = 1$（实现"取反加 1"）；溢出标志由一个异或门 $C_n \oplus C_{n-1}$ 产生。加法器的门级结构见第 4 章组合逻辑电路。

## 逻辑推导

<Mode show="basic">

**为什么"取反加 1"等于 $2^n + X$？** 设 $X<0$，$\lvert X\rvert$ 的 $n$ 位二进制为 $B$。把 $B$ 的每一位取反，等于 $(2^n - 1) - B$（全 1 减去 $B$）。再加 1 就是 $2^n - B = 2^n + X$。

</Mode>

<Mode show="deep">

**为什么 $V = C_n \oplus C_{n-1}$？** 设两个加数的符号位为 $a$、$b$，进入符号位的进位为 $c = C_{n-1}$，则结果符号位与符号位进位为

$$
s = a \oplus b \oplus c,\qquad C_n = ab + (a\oplus b)c
$$

分三种情况：

1. $a=b=0$（两正数）：$C_n = 0$，$s = c$。结果为负（$s=1$）即溢出，所以 $V = c = C_n \oplus C_{n-1}$。
2. $a=b=1$（两负数）：$C_n = 1$，$s = c$。结果为正（$s=0$）即溢出，所以 $V = \overline{c} = 1 \oplus c = C_n \oplus C_{n-1}$。
3. $a \ne b$（异号）：真实结果的绝对值不超过两者中较大的一个，**不可能溢出**；此时 $C_n = c$，$C_n \oplus C_{n-1} = 0$。

三种情况都与 $V = C_n \oplus C_{n-1}$ 一致。符号位法写成逻辑式就是

$$
V = \overline{a}\,\overline{b}\,s + ab\,\overline{s}
$$

**双符号位（变形补码）**：把符号位复制一份，用 $n+1$ 位运算。结果的两个符号位为 $00$、$11$ 表示正常，$01$ 表示正溢出，$10$ 表示负溢出。它与 $C_n \oplus C_{n-1}$ 本质相同。

**符号扩展**：把 $n$ 位补码扩展成更多位时，在左边**重复符号位**，例如 4 位 $1011$（$-5$）扩展为 8 位 $11111011$，数值不变。

</Mode>

<Mode show="exam">

**标准步骤（通行题型：补码加减与溢出）**

1. 确认字长 $n$ 和表示范围 $-2^{n-1} \sim 2^{n-1}-1$；真实结果超出范围就一定溢出。
2. 把两个操作数写成 $n$ 位补码；减法先把减数变成 $[-Y]_{\text{补}}$。
3. 列竖式相加，**同时标出 $C_{n-1}$ 和 $C_n$**，丢弃 $C_n$。
4. 用 $C_n \oplus C_{n-1}$ 判溢出，再用"同号相加、结果变号"复核。
5. 未溢出时把结果补码还原成十进制核对。

</Mode>

## 典型例题

<Example title="例 1 · 三种码">

写出 $X = -45$ 的 8 位原码、反码、补码。

<Solution>

$45 = (00101101)_2$。

- $[X]_{\text{原}} = 10101101$（符号位置 1）
- $[X]_{\text{反}} = 11010010$（数值位取反，符号位不变）
- $[X]_{\text{补}} = 11010011$（反码 $+1$）

检验：$11010011 = 211$，$211 - 256 = -45$。

</Solution>

</Example>

<Example title="例 2 · 补码加法（不溢出）">

用 8 位补码计算 $37 + (-58)$。

<Solution>

$[37]_{\text{补}} = 00100101$，$[-58]_{\text{补}} = 11000110$（$58 = 00111010$，取反加 1）。

$$
\begin{array}{r}
00100101 \\
+\ 11000110 \\
\hline
11101011
\end{array}
$$

$C_n = 0$，$C_{n-1} = 0$，$V = 0$，不溢出。结果 $11101011 = 235 - 256 = -21$，正确。

</Solution>

</Example>

<Example title="例 3 · 正溢出与负溢出">

用 8 位补码分别计算 $100 + 50$ 与 $(-100) + (-50)$，判断是否溢出。

<Solution>

$100 + 50$：$01100100 + 00110010 = 10010110$。两正数相加结果符号位为 1；竖式中 $C_{n-1} = 1$，$C_n = 0$，$V = 1$，**正溢出**。若误读结果，会得到 $-106$。

$(-100) + (-50)$：$10011100 + 11001110 = 1\,01101010$，丢弃最高进位后为 $01101010$。两负数相加结果为正；$C_{n-1} = 0$，$C_n = 1$，$V = 1$，**负溢出**。若误读结果，会得到 $+106$。

两题的真实结果 $\pm 150$ 都超出了 8 位补码范围 $-128 \sim 127$。

</Solution>

</Example>

<Example title="例 4 · 补码减法">

用 4 位补码计算 $5 - 7$。

<Solution>

$[5]_{\text{补}} = 0101$，$[7]_{\text{补}} = 0111$，$[-7]_{\text{补}} = 1000 + 1 = 1001$。

$0101 + 1001 = 1110$，$C_n = 0$，$C_{n-1} = 0$，不溢出。$1110 = 14 - 16 = -2$，正确。

</Solution>

</Example>

## 常见错误

<Callout type="pitfall" title="把最高位进位当作溢出">

**$C_n = 1$ 不等于溢出。** 例如 8 位 $(-35) + (-64)$：$11011101 + 11000000 = 1\,10011101$，$C_n = 1$，但 $C_{n-1}$ 也是 1，$V = 0$，结果 $10011101 = -99$ 完全正确。溢出看的是 $C_n$ 与 $C_{n-1}$ **是否不同**。

</Callout>

<Callout type="pitfall">

- 求反码时**符号位不取反**；但由 $[Y]_{\text{补}}$ 求 $[-Y]_{\text{补}}$ 时**连同符号位一起取反再加 1**。两个"取反"的对象不同。
- $n$ 位补码的最小值是 $-2^{n-1}$（8 位为 $-128$，代码 $10000000$），它**没有对应的 $n$ 位原码和反码**。
- 异号相加永远不会溢出，不要在异号情况下"判出"溢出。

</Callout>

## 知识总结

<Mode show="exam">

**考前速记**

- 8 位范围：原码/反码 $-127 \sim 127$，补码 $-128 \sim 127$。
- 负数补码 $=$ 反码 $+1$ $= 2^n + X$；正数三码相同。
- $V = C_n \oplus C_{n-1}$；等价于"同号相加，结果符号与加数相反"。
- 减法：$X - Y = X + [-Y]_{\text{补}}$，$[-Y]_{\text{补}}$ = 全部取反加 1。

</Mode>

| | 原码 | 反码 | 补码 |
|---|---|---|---|
| 0 的表示 | 两种 | 两种 | 一种 |
| 范围（$n$ 位） | $\pm(2^{n-1}-1)$ | $\pm(2^{n-1}-1)$ | $-2^{n-1} \sim 2^{n-1}-1$ |
| 加减法 | 需比较符号与大小 | 需循环进位 | 直接相加，丢弃 $C_n$ |

## 后续知识关联
