## 直观解释

<Mode show="basic">

**时钟沿就是"拍照"的瞬间。** `always @(posedge clk)` 的意思是：每当时钟上升沿到来，就执行一次块里的语句。块里被赋值的 `reg`，在两次时钟沿之间保持不变——这正是触发器。

**`<=` 像"大家先拍照，再一起换衣服"。** 三个人排成一排，每人都要换成"左边那个人现在穿的衣服"。

- 用 `<=`（非阻塞）：大家先同时看一眼左边的人穿什么（采样），再同时换（更新）。结果是衣服整体往右移了一位——移位寄存器。
- 用 `=`（阻塞）：第一个人先换好，第二个人再去看第一个人——看到的已经是新衣服了。一拍之内，最左边的衣服"穿透"到了最右边。

本平台的电路仿真也是这样做的：每个时钟沿**先统一采样所有触发器的输入，再统一更新**。`<=` 就是这个规则在代码里的写法。

</Mode>

<Mode show="deep">

Verilog 仿真器在每个仿真时刻内按**区域**处理事件。简化地说：

1. **活跃区**：执行被触发的进程。遇到阻塞赋值 `a = expr;`，立即求值并写入 `a`；遇到非阻塞赋值 `a <= expr;`，**立即求出右值，但把"写入 `a`"这件事排进 NBA 区**。
2. **NBA 区**：活跃区没有事件后，把排队的非阻塞赋值一次性提交。提交引起的信号变化可能再触发组合进程，于是回到活跃区，直到该时刻稳定。

所以在同一个时钟沿触发的所有时序块中，用 `<=` 时，每条语句读到的都是**时钟沿之前的旧值**，与语句顺序、块的执行顺序都无关——这正是同步电路"两阶段更新"的数学模型：

$$
\mathbf{Q}^{n+1}=\delta(\mathbf{Q}^n,\mathbf{X}^n)
$$

右边全部用现态。用 `=` 时，后执行的语句会读到先执行语句**刚写入的新值**。在同一个块里这个顺序是确定的（从上到下），只是结果不是你想要的电路；在**不同的块**之间，标准没有规定哪个块先执行，结果就取决于仿真器——这就是竞争。

本平台解释器的实现与此一致：时钟沿到来时按源代码顺序执行被触发的块，阻塞赋值立即生效，非阻塞赋值先求右值、排队，最后统一提交；同一时刻内的多轮更新用 delta 序号区分。

</Mode>

<Mode show="exam">

**本课考点速览**：

- 时序块 `always @(posedge clk)` 一律用 `<=`；组合块 `always @(*)` 一律用 `=`。
- 异步复位：复位信号写进敏感列表 `@(posedge clk or negedge rst_n)`，块内第一个 `if` 判复位；同步复位：敏感列表只有时钟。
- 一个信号只在一个 `always` 块里赋值。
- 计数器：`q <= q + 1`；模 $N$ 同步清零式计数器比较的是 $N-1$。
- 三段式状态机：① 状态寄存器（时序，`<=`）② 次态逻辑（组合，`=`，先给默认值）③ 输出逻辑（Moore 只看现态，Mealy 还看输入）。
- Testbench：没有端口；`reg` 驱动输入、`wire` 接输出；`always #5 clk = ~clk;` 产生时钟；`initial` 里给激励、检查、`$finish`。

</Mode>

## 基本原理

### 1. 边沿触发器：always @(posedge clk)

```verilog
module dff (
  input  wire clk,
  input  wire rst_n,
  input  wire d,
  output reg  q
);
  always @(posedge clk or negedge rst_n)
    if (!rst_n) q <= 1'b0;   // 异步复位：rst_n 一变低就清零
    else        q <= d;      // 上升沿采样 d
endmodule
```

- `posedge clk` 表示时钟上升沿，`negedge clk` 表示下降沿。实验 A 的 JK 计数器是下降沿触发的，写成 Verilog 就是 `always @(negedge clk)`。
- 只有时钟沿（或异步复位沿）才执行这个块，所以 `q` 在两次沿之间保持——综合出来是 D 触发器。
- `q` 在复位之前是 x（未初始化），这与真实电路上电状态不确定是一致的。所以时序电路**都应该有复位**。

### 2. 异步复位与同步复位

| | 异步复位 | 同步复位 |
|---|---|---|
| 写法 | `always @(posedge clk or negedge rst_n)` | `always @(posedge clk)` |
| 块内 | `if (!rst_n) q <= 0; else …` | `if (!rst_n) q <= 0; else …` |
| 生效时刻 | `rst_n` 一变低立即清零，不等时钟 | 等到下一个时钟有效沿才清零 |
| 对应的器件行为 | 74LS161 的 $\overline{R_D}$（异步清零） | 74LS163 的同步清零 |

在本平台解释器中实际运行：

- 异步复位（示例 `dff`）：`q = 1` 时把 `rst_n` 置 0，不加时钟，`q` 立即变为 0。
- 同步复位：`q = 1` 时把 `rst_n` 置 0，`q` 仍为 1；再来一个上升沿，`q` 才变为 0。

<Callout type="warn" title="异步复位的写法是固定的">

异步复位信号必须同时出现在敏感列表（`negedge rst_n`）和块内第一个 `if` 中，并且 `if` 判断的极性要与边沿一致（`negedge rst_n` 配 `if (!rst_n)`）。敏感列表中**不能混用边沿与电平**：`always @(posedge clk or rst_n)` 是错误写法，本平台解释器会直接报错。

</Callout>

### 3. 阻塞赋值与非阻塞赋值

| | 阻塞赋值 `=` | 非阻塞赋值 `<=` |
|---|---|---|
| 执行方式 | 立即求值、立即写入；后面的语句读到新值 | 立即求右值，写入推迟到本时刻所有块执行完之后统一进行 |
| 对应的硬件思维 | 组合逻辑的"逐级计算" | 同步电路的**两阶段更新**（先统一采样，再统一更新） |
| 用在 | `always @(*)` 组合块 | `always @(posedge clk)` 时序块 |

**例 A：同一个块中用 `=` 写移位寄存器。** 对比示例 `shift-nb` 与 `shift-b`：

```verilog
always @(posedge clk) begin      // 正确：非阻塞
  q0 <= din;
  q1 <= q0;
  q2 <= q1;
end

always @(posedge clk) begin      // 错误：阻塞
  q0 = din;
  q1 = q0;    // 读到的是刚更新的 q0
  q2 = q1;
end
```

初值 `q0 q1 q2 = 000`，输入 `din` 逐拍为 `1 0 0 1 1 0 0`，在本平台解释器中运行的结果：

$$
\begin{array}{c|ccccccc}
\text{拍} & 1&2&3&4&5&6&7\\\hline
\text{din} & 1&0&0&1&1&0&0\\
q_0q_1q_2\ (\texttt{<=}) & 100&010&001&100&110&011&001\\
q_0q_1q_2\ (\texttt{=}) & 111&000&000&111&111&000&000
\end{array}
$$

用 `<=` 时数据每拍右移一位；用 `=` 时三个寄存器每拍都等于 `din`，综合出来实际上只剩**一个**触发器，另外两个被优化成连线。

<Mode show="deep">

**倒过来写也"能用"，但不要这样做。** 把阻塞赋值的顺序倒过来——`q2 = q1; q1 = q0; q0 = din;`——每条语句读到的恰好都是旧值，解释器运行结果与 `<=` 版本相同。但这种写法依赖语句顺序：以后有人调整顺序、或者把一部分移到另一个块里，电路就悄悄变了。用 `<=` 时，语句以任何顺序书写结果都一样，这才是"描述电路"而不是"描述过程"。

</Mode>

**例 B：不同 `always` 块用 `=` 产生竞争。** 设 `a = 0`、`b = 1`，想在每个时钟沿交换二者：

```verilog
always @(posedge clk) a = b;     // 块 1
always @(posedge clk) b = a;     // 块 2
```

两个块在同一个时钟沿被触发。若块 1 先执行，`a` 先变成 1，块 2 读到新的 `a`，结果 `a = b = 1`；若块 2 先执行，结果 `a = b = 0`。**标准 Verilog 没有规定这两个块的执行顺序**，不同仿真器、甚至同一仿真器的不同版本都可能给出不同结果，而综合出的硬件又是另一回事。本平台解释器按源代码顺序执行（得到 `a = b = 1`；把两个块对调则得到 `a = b = 0`），并给出"竞争"警告。

改成 `<=` 后，两个块读到的都是时钟沿之前的旧值，每拍稳定地交换：解释器运行结果为第 1 拍 `a b = 1 0`、第 2 拍 `0 1`，不再有警告。

<Callout type="tip" title="三条规则">

1. 时序块（`@(posedge clk)`）用 `<=`；组合块（`@(*)`）用 `=`。
2. 同一个块里不要混用 `=` 和 `<=`。
3. 一个信号只在一个 `always` 块里被赋值。

</Callout>

### 4. 计数器的写法

**二进制加法计数器**（示例 `counter3`）：

```verilog
always @(posedge clk or negedge rst_n)
  if (!rst_n) q <= 3'd0;
  else        q <= q + 3'd1;   // 3 位加法，111 + 1 自然回到 000

assign c = &q;                 // 计到 111 时进位
```

一句 `q <= q + 3'd1` 就代替了「同步时序电路分析」中三组驱动方程 $J_0=K_0=1$、$J_1=K_1=Q_0$、$J_2=K_2=Q_0Q_1$——综合工具会自己求出加法器的逻辑。

**任意模数（同步清零式）**（示例 `counter10`）：

```verilog
always @(posedge clk or negedge rst_n)
  if (!rst_n)          q <= 4'd0;
  else if (en)
    if (q == 4'd9)     q <= 4'd0;     // 计到 9，下一拍回 0
    else               q <= q + 4'd1;

assign co = en & (q == 4'd9);
```

比较的是 **9** 而不是 10：判断发生在 `q = 9` 的这一拍，下一个时钟沿把 `q` 置为 0，10 这个状态根本不出现。这与 74LS163 的同步清零法"译码 $N-1$"是同一个道理；而 74LS161 的异步清零法译码 $N$，会出现一个短暂的过渡状态（见「计数器与 74LS161 任意进制」）。`en = 0` 时 `if (en)` 不成立，没有任何赋值，`q` 保持——在时序块中这正是我们想要的"保持"，**不是**错误。

<Callout type="note" title="时序块中漏写 else 不会推断锁存器">

组合块中漏赋值会推断锁存器；时序块中漏赋值只是"本拍保持"，综合成带使能的触发器，这是正常写法。区分的关键在于块的类型。

</Callout>

### 5. 三段式状态机

以「序列检测器」中的 101 检测器（Mealy 型、可重叠）为例，示例 `fsm101` 的核心代码：

```verilog
localparam S0 = 2'd0,   // 还没有匹配
           S1 = 2'd1,   // 已匹配 "1"
           S2 = 2'd2;   // 已匹配 "10"
reg [1:0] state, next;

// ① 状态寄存器：时序逻辑，非阻塞赋值
always @(posedge clk or negedge rst_n)
  if (!rst_n) state <= S0;
  else        state <= next;

// ② 次态逻辑：组合逻辑，先给默认值
always @(*) begin
  next = S0;
  case (state)
    S0: next = x ? S1 : S0;
    S1: next = x ? S1 : S2;
    S2: next = x ? S1 : S0;
  endcase
end

// ③ 输出逻辑：Mealy 型，与现态和当前输入都有关
always @(*) begin
  y = 1'b0;
  if (state == S2 && x) y = 1'b1;
end
```

- 三段分别对应同步时序电路框图中的**状态寄存器、次态逻辑、输出逻辑**，与状态表一一对应：`case` 的每个分支就是状态表的一行。
- `localparam` 给状态起名字，编码可以随时修改而不动其他代码。
- 第 ② 段开头的 `next = S0;` 有两个作用：保证每条路径都有赋值（不推断锁存器）；未用编码 `2'b11` 的次态回到 $S_0$，电路**能自启动**。
- **Moore 型**的输出只看现态，可以写成 `assign y = (state == S2);`；**Mealy 型**的输出还要看输入，如上面的 `state == S2 && x`。

实验 E 中由序列检测器生成的"行为级"代码也是这种三段式结构：次态块和输出块开头都先给默认值，并带 `default` 分支。

<Mode show="basic">

**三段式就像一张"值班表"**：① 状态寄存器是"现在谁在值班"，每个时钟沿换一次班；② 次态逻辑是"下一班该谁"，看现在谁在班、外面发生了什么；③ 输出逻辑是"值班的人该做什么"。三件事分开写，任何一件改动都不会牵连另外两件。

</Mode>

### 6. Testbench 的结构

Testbench 是一个**专门用于仿真的模块**：它没有端口，内部产生时钟和激励，例化被测模块（DUT），检查输出。Testbench 使用 `initial`、`#` 延迟、`$display` 等**不可综合**的语法，它不会变成硬件。下面是为示例 `counter10` 写的自检 Testbench：

```verilog
`timescale 1ns/1ps
module tb_counter10;                 // ① 没有端口
  reg        clk = 1'b0;
  reg        rst_n, en;              //   驱动 DUT 输入的用 reg
  wire [3:0] q;                      //   接 DUT 输出的用 wire
  wire       co;
  reg  [3:0] expect_q;
  integer    i, errors;

  // ② 例化被测模块，按名连接
  counter10 dut (.clk(clk), .rst_n(rst_n), .en(en), .q(q), .co(co));

  // ③ 时钟：每 5 ns 翻转一次，周期 10 ns
  always #5 clk = ~clk;

  // ④ 激励与自检
  initial begin
    errors = 0;
    rst_n = 1'b0; en = 1'b1;         // 先复位
    #12 rst_n = 1'b1;                // 在两个时钟沿之间撤销复位
    expect_q = 4'd0;
    for (i = 0; i < 25; i = i + 1) begin
      @(posedge clk); #1;            // 时钟沿之后稍等再检查
      expect_q = (expect_q == 4'd9) ? 4'd0 : expect_q + 4'd1;
      if (q !== expect_q) begin
        errors = errors + 1;
        $display("t=%0t  q=%0d，应为 %0d", $time, q, expect_q);
      end
    end
    if (errors == 0) $display("PASS");
    else             $display("FAIL：%0d 处不一致", errors);
    $finish;
  end
endmodule
```

<Mode show="basic">

**Testbench 就是一张"考卷"**：被测模块是考生，Testbench 负责出题（激励）、打铃（时钟）、对答案（自检），最后报分数（PASS/FAIL）。考卷本身不会被做进芯片里。

</Mode>

要点：

- **时钟产生**：`always #5 clk = ~clk;`，配合 `` `timescale 1ns/1ps `` 得到 10 ns 周期（100 MHz）。
- **激励避开时钟沿**：在两个时钟沿之间改变输入（上例在 12 ns 撤销复位），避免 Testbench 与 DUT 在同一时刻读写同一信号而产生竞争。
- **自检**：用期望值逐拍比较，最后打印 PASS/FAIL，而不是靠眼睛看波形。`!==` 把 x 也当作一个值来比较，DUT 输出 x 时会被判为不一致，这是自检中常用的写法。

<Callout type="model" title="本平台不运行 Testbench">

本平台的 Verilog 子集解释器**不执行** `initial`、`#` 延迟、`$display`/`$finish` 等系统任务，也不支持 `integer`、`for` 和 `===`/`!==`——上面这段 Testbench **没有在本平台运行过**。在实验台中，时钟和激励由页面上的按钮（单步、运行 8 拍、按示例激励走一拍）代替 Testbench 施加。

需要运行 Testbench 时，请把设计和 Testbench 保存为 `.v` 文件，在 iverilog 等仿真器中运行，例如 `iverilog -o tb counter10.v tb_counter10.v && vvp tb`。**实验 E** 的"电路 ↔ Verilog"对照页可以下载一个**由本平台电路仿真结果生成的自检 Testbench**：它以电路仿真引擎逐拍算出的输出为期望值，每个时钟周期结束前检查一次，最后打印 PASS/FAIL。

</Callout>

## 电路结构

本课在**逻辑层 / 理想模型**下讨论：所有触发器共用时钟、同时更新，门延迟忽略；建立时间、保持时间等电气约束见「时序约束与最高时钟频率」。

时序 Verilog 代码与电路的对应关系：

| 代码 | 电路 |
|---|---|
| `always @(posedge clk) q <= d;` | D 触发器（上升沿） |
| `always @(negedge clk) …` | 下降沿触发器 |
| 敏感列表中的 `negedge rst_n` + `if (!rst_n)` | 触发器的异步清零端（低电平有效） |
| 时序块中的 `if (!rst_n)`（敏感列表无 `rst_n`） | D 端前的选择逻辑（同步清零） |
| 时序块中 `if (en) q <= …;`（无 `else`） | 带使能的触发器（`en = 0` 时保持） |
| `q <= q + 1` | 加法器 + $n$ 位寄存器 |
| 三段式状态机 | 状态寄存器 + 次态组合逻辑 + 输出组合逻辑 |
| 例化 `jkff` 三次并连线 | 结构化描述，与逻辑图一一对应 |

<Mode show="deep">

**行为描述与结构描述。** 示例 `jk-structural` 先写一个 JK 触发器模块（`q <= j & ~q | ~k & q`，即特性方程），再例化三次、按驱动方程连线——这就是实验 A 的电路图，属于**结构化描述**。示例 `counter3` 只写 `q <= q + 1`，属于**行为描述**。二者功能相同（解释器中运行，计数序列都是 `000→001→…→111→000`），区别只是触发沿：`jk-structural` 是下降沿，`counter3` 是上升沿。

综合工具一般把行为描述映射成 D 触发器加组合逻辑——FPGA 中的触发器基本都是 D 型，JK 触发器的特性方程会被折算进触发器前面的查找表。

</Mode>

## 逻辑推导

### 1. 由驱动方程写 Verilog

已知实验 A 的驱动方程 $J_0=K_0=1$、$J_1=K_1=Q_0$、$J_2=K_2=Q_0Q_1$（下降沿触发）。把 JK 触发器的特性方程 $Q^{n+1}=J\overline{Q^n}+\overline{K}Q^n$ 写成非阻塞赋值，三个触发器写在同一个时序块里：

```verilog
wire j1 = q0, j2 = q0 & q1;
always @(negedge clk) begin
  q0 <= 1'b1 & ~q0 | ~1'b1 & q0;   // J0 = K0 = 1，化简即 q0 <= ~q0
  q1 <= j1 & ~q1 | ~j1 & q1;       // J1 = K1 = Q0，即 q1 <= q1 ^ q0
  q2 <= j2 & ~q2 | ~j2 & q2;       // J2 = K2 = Q0·Q1
end
```

三条 `<=` 的右边用的都是时钟沿之前的 $Q^n$，正是状态方程 $Q_i^{n+1}=f(Q^n)$ 的含义。若误写成 `=`，`q1` 那一行读到的将是已经翻转过的 `q0`，计数序列就错了。

### 2. 由状态表写三段式状态机

101 检测器（Mealy、可重叠）的化简状态表（次态/输出）：

$$
\begin{array}{c|cc}
\text{现态} & X=0 & X=1\\\hline
S_0 & S_0/0 & S_1/0\\
S_1 & S_2/0 & S_1/0\\
S_2 & S_0/0 & S_1/1
\end{array}
$$

- 第 ② 段：表中每一行写成一个 `case` 分支，`X=1` 列与 `X=0` 列用 `x ? … : …` 选出。
- 第 ③ 段：只有 $S_2$、$X=1$ 时输出 1，写成 `if (state == S2 && x) y = 1'b1;`。

**逐拍推演**：复位后输入 `x` 为 `1 0 1 0 1 1 0 1`。

$$
\begin{array}{c|cccccccc}
\text{拍} & 1&2&3&4&5&6&7&8\\\hline
x & 1&0&1&0&1&1&0&1\\
\text{现态} & S_0&S_1&S_2&S_1&S_2&S_1&S_1&S_2\\
y & 0&0&1&0&1&0&0&1
\end{array}
$$

第 3、5、8 拍输出 1（第 5 拍复用了第 3 拍末尾的 1，这就是"可重叠"）。在解释器中运行示例 `fsm101`，每拍在时钟沿之前读取 `y`，结果相同。Mealy 型输出在时钟沿**之前**就随输入出现，所以读 Mealy 输出要在本拍时钟沿之前读。

### 3. 读代码画波形的方法

读时序代码画波形，就是「同步时序电路分析」的方法换一种写法：

1. 找出所有时序块和它们的触发沿；标出异步复位。
2. 对每个有效沿，用**沿之前**的输入和现态，计算所有 `<=` 的右边。
3. 统一更新，得到沿之后的新状态；组合输出（`assign`）立即随之变化。
4. 异步复位一有效就立即改写状态，不等时钟沿。

<Example title="例 1  读代码写出逐拍输出">

```verilog
module cnt2 (
  input  wire       clk,
  input  wire       rst_n,
  input  wire       ld,
  input  wire [1:0] d,
  output reg  [1:0] q
);
  always @(posedge clk or negedge rst_n)
    if (!rst_n)  q <= 2'b00;
    else if (ld) q <= d;
    else         q <= q + 2'b01;
endmodule
```

每个时钟上升沿之前的输入依次为：① `rst_n = 0`；② `rst_n = 1, ld = 1, d = 2'b10`；③ `ld = 0`；④ 不变；⑤ 不变；⑥ `ld = 1, d = 2'b01`；⑦ `ld = 0`。写出每个上升沿之后的 `q`。

<Solution>

- ①：异步复位，`q = 00`；
- ②：`ld = 1`，置数，`q = 10`；
- ③④⑤：加 1 计数，`11`、`00`（2 位加法 `11 + 1` 溢出回到 `00`）、`01`；
- ⑥：`ld = 1`，置数 `01`，`q = 01`；
- ⑦：加 1，`q = 10`。

逐拍结果：`00 10 11 00 01 01 10`（与本平台解释器运行结果一致）。注意 `if … else if …` 的先后体现了优先级：复位 > 置数 > 计数。

</Solution>
</Example>

<Example title="例 2  找错：时序块中的阻塞赋值">

下面的代码想实现"每拍把 `a`、`b` 交换"，初值 `a = 0`、`b = 1`。指出问题并修改。

```verilog
always @(posedge clk) a = b;
always @(posedge clk) b = a;
```

<Solution>

两个块在同一个时钟沿被触发，都用阻塞赋值，一个写 `a`、另一个读 `a`——这是**竞争**，结果取决于两个块的执行顺序，标准 Verilog 没有规定该顺序。先执行第一个块得到 `a = b = 1`，先执行第二个块得到 `a = b = 0`，两种情况都没有完成交换。

修改：两处都改成 `<=`。

```verilog
always @(posedge clk) a <= b;
always @(posedge clk) b <= a;
```

两个块读到的都是时钟沿之前的旧值，第 1 拍后 `a b = 1 0`，第 2 拍后 `0 1`，稳定交换（解释器运行结果一致，且不再有竞争警告）。

</Solution>
</Example>

<Example title="例 3  写一个模 12 计数器">

写出一个 4 位、异步复位、计到 11 后回到 0 的计数器，并在 `q = 11` 时输出 `co = 1`。

<Solution>

```verilog
module counter12 (
  input  wire       clk,
  input  wire       rst_n,
  output reg  [3:0] q,
  output wire       co
);
  always @(posedge clk or negedge rst_n)
    if (!rst_n)            q <= 4'd0;
    else if (q == 4'd11)   q <= 4'd0;
    else                   q <= q + 4'd1;

  assign co = (q == 4'd11);
endmodule
```

比较 $N-1=11$，不是 12。复位后连续 13 个时钟沿，解释器运行得到 `q` 依次为 1、2、…、11、0、1，`co` 只在 `q = 11` 那一拍为 1。

</Solution>
</Example>

<Example title="例 4  写一个 Moore 型 11 检测器">

输入 `x` 连续出现两个或更多个 1 时，输出 `y = 1`（Moore 型，输出只取决于现态）。用三段式写出，并求复位后输入 `x = 0 1 1 1 0 1 1` 时每个时钟沿之后的 `y`。

<Solution>

状态：$S_0$（上一位不是 1）、$S_1$（刚收到一个 1）、$S_2$（已连续收到至少两个 1）。

```verilog
module det11 (
  input  wire clk,
  input  wire rst_n,
  input  wire x,
  output wire y
);
  localparam S0 = 2'd0, S1 = 2'd1, S2 = 2'd2;
  reg [1:0] state, next;

  always @(posedge clk or negedge rst_n)      // ① 状态寄存器
    if (!rst_n) state <= S0;
    else        state <= next;

  always @(*) begin                           // ② 次态逻辑
    next = S0;
    case (state)
      S0: next = x ? S1 : S0;
      S1: next = x ? S2 : S0;
      S2: next = x ? S2 : S0;
      default: next = S0;
    endcase
  end

  assign y = (state == S2);                   // ③ Moore 输出
endmodule
```

逐拍：状态依次为 $S_0,S_1,S_2,S_2,S_0,S_1,S_2$，所以 `y = 0 0 1 1 0 0 1`（解释器运行结果一致）。Moore 型的输出比同样功能的 Mealy 型晚一拍出现，但不会随输入的毛刺而变化。

</Solution>
</Example>

**题型 1：读代码画波形 / 写出第 $n$ 拍的输出。**

1. 标出时钟沿类型、异步复位；
2. 列表：每拍一行，写"沿之前的输入、现态"；
3. 用**沿之前**的值计算所有 `<=` 的右边，再统一更新；`=` 则按语句顺序立即更新；

**题型 3：写计数器。** 标准格式：异步复位 + `if (q == N-1) q <= 0; else q <= q + 1;`，进位输出用 `assign`。注意位宽 $\lceil\log_2 N\rceil$。

## 常见错误

1. **时序块用 `=`**：移位寄存器一拍穿透；不同块之间产生竞争。时序块一律用 `<=`。
2. **组合块用 `<=`**：功能上常常仍能仿真出正确结果，但违背规范、容易与时序块的语义混淆。本平台解释器会给出警告并按 `=` 执行。
3. **异步复位写法错误**：复位信号没写进敏感列表（变成同步复位）、极性与 `if` 不一致、敏感列表中混用边沿与电平。
4. **同一信号在多个 `always` 块中赋值**：多驱动，综合报错。
5. **模 $N$ 计数器比较 $N$**：同步清零式应比较 $N-1$。
6. **状态机次态块不写默认值**：可能推断锁存器，且未用编码的去向不确定（自启动无法保证）。
7. **把 Testbench 当成可综合代码**，或以为本平台解释器能运行 Testbench。`initial`、`#`、`$display` 要在 iverilog 等仿真器中运行。
8. **Testbench 在时钟沿同一时刻改变输入**：与 DUT 采样产生竞争。在两个沿之间改变输入。

## 知识总结

- `always @(posedge clk)` 描述边沿触发器；异步复位写进敏感列表 `or negedge rst_n` 并在块内第一个 `if` 判断，同步复位只在时钟沿生效。
- `<=`：先统一求右值、再统一更新，对应同步电路的两阶段更新；`=`：立即更新。时序块用 `<=`，组合块用 `=`，一个信号只在一个块里赋值。
- 同一块中用 `=` 写移位寄存器会穿透；不同块用 `=` 读写同一变量会产生竞争。
- 计数器：`q <= q + 1`；模 $N$ 同步清零比较 $N-1$；时序块中不写 `else` 等于"保持"，不是锁存器。
- 三段式状态机：状态寄存器（时序）+ 次态逻辑（组合，默认值）+ 输出逻辑（Moore/Mealy）。
- Testbench：无端口、产生时钟与激励、例化 DUT、自检；本平台解释器不运行它，需在 iverilog 等仿真器中运行；实验 E 可下载由电路仿真结果生成的自检 Testbench。
